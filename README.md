# MD Akhtar Ali — Luxury Portfolio

A premium dark/gold React + Vite portfolio website.

## Run locally

```bash
npm install
npm run dev
```

Then open the localhost URL shown by Vite.

## Build

```bash
npm run build
npm run preview
```

## Important edits

Open `src/main.jsx` and replace:
- `your-email@example.com`
- LinkedIn `href="#"`
- GitHub `href="#"`

You can also update project links and project descriptions there.

The profile photo is already included at:
`src/assets/profile.jpg`
